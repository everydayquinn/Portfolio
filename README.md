SQL & Power BI Analytics Portfolio

Production-style SQL Server → Power BI analytics pipeline built from anonymized real-world web performance data.

I designed and implemented a normalized database schema with calendar and special-date dimensions, safe metric calculations, and BI-ready SQL views consumed directly by Power BI dashboards. The system supports time-based and event-driven analysis (day-of-week, holidays, campaigns) while guarding against common data issues such as missing values and divide-by-zero errors.

The dataset is intentionally limited; deeper statistical conclusions would be speculative rather than defensible. This portfolio emphasizes system design, data integrity, and analytical rigor over overstated insights.

I approach analytics with a systems mindset: even when working within an existing stack, I aim to understand the full data pipeline end-to-end — well enough to rebuild, refactor, or troubleshoot it if required.
